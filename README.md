# ALVIN CHEN XIANG YI — Advanced Guitarist Portfolio

This is the editable website project. `index.html` is the entry page.

## Structure
- `index.html` — website structure/content
- `css/style.css` — visual design/responsive styling
- `js/script.js` — scroll reveal, video autoplay/pause, sound control
- `assets/images/` — photos
- `assets/videos/podium.mp4` — Podium performance video used in the Hero and STICK'N BITE section

## GitHub Pages
Upload the contents of this folder to the repository root so `index.html` is at the top level. Then go to **Settings → Pages** and choose **Deploy from a branch → main → / (root)**, then Save.

The site will be available at:
`https://erinephang323-pixel.github.io/alvin-portfolio/`

## Editing
Change text in `index.html`, visual styling in `css/style.css`, and interactions in `js/script.js`. Replace images/videos inside `assets/` while keeping the same filenames, or update the paths in `index.html`.
